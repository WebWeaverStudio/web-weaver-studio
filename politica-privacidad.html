2. Datos que recabamos y finalidad

Este sitio web puede recopilar los siguientes datos personales:

  • Datos de contacto (nombre, correo electrónico, teléfono): cuando el usuario se pone en contacto con nosotros a través de WhatsApp, correo electrónico u otros medios de comunicación. La finalidad es atender su consulta y gestionar la relación comercial.

3. Base jurídica del tratamiento

El tratamiento de sus datos se basa en:

  • El consentimiento del usuario al ponerse en contacto con nosotros (art. 6.1.a RGPD).
  • La ejecución de un contrato o medidas precontractuales a petición del interesado (art. 6.1.b RGPD).
  • El interés legítimo del responsable para el envío de comunicaciones comerciales relacionadas con los servicios contratados (art. 6.1.f RGPD).

4. Conservación de los datos

Los datos se conservarán durante el tiempo necesario para cumplir con la finalidad para la que fueron recabados y para atender las posibles responsabilidades legales derivadas del tratamiento.

5. Destinatarios de los datos

Los datos no serán cedidos a terceros salvo obligación legal. Podemos utilizar proveedores de servicios externos (herramientas de análisis web) que actúan como encargados del tratamiento bajo contrato y con las garantías exigidas por el RGPD.

6. Derechos del usuario

El usuario puede ejercer en cualquier momento los siguientes derechos:

  • Acceso: conocer qué datos tratamos sobre usted.
  • Rectificación: corregir datos inexactos o incompletos.
  • Supresión: solicitar la eliminación de sus datos.
  • Oposición y limitación: oponerse o limitar determinados tratamientos.
  • Portabilidad: recibir sus datos en formato estructurado.

Para ejercer estos derechos, puede escribirnos a jaime.herranz.hecht@gmail.com. También tiene derecho a presentar una reclamación ante la Agencia Española de Protección de Datos (www.aepd.es).

7. Transferencias internacionales

No se realizan transferencias internacionales de datos fuera del Espacio Económico Europeo, salvo cuando los proveedores de servicios utilizados ofrezcan garantías adecuadas conforme al RGPD.

8. Menores de edad

Este sitio web no está dirigido a menores de 14 años. No recabamos conscientemente datos personales de menores.

9. Cambios en esta política

Web Weaver Studio se reserva el derecho a modificar esta Política de Privacidad para adaptarla a cambios legislativos o de servicio. La versión vigente siempre estará accesible en esta página.
